<blockquote>
<p>A structure is a user-defined type that allows storing and moving multiple values of different types together. A structure is defined as follows:</p>
</blockquote>
<pre><code node="[object Object]">struct [structure name] {
element definition;
element definition;
...
element definition;
} [one or more variables];
</code></pre>
<blockquote>
<p>Using structures allows grouping related data and provides the ability to later modify the passed data without changing function headers.</p>

<p>Need to write tree traversal functions. Since there is no information on the exact order in which the AI documentation modules must be arranged for correct loading, you need to write 3 different traversal functions:</p>
<ul>
<li>infix — elements will be displayed in ascending order (left subtree -&gt; root -&gt; right subtree);</li>
<li>prefix — elements will be displayed in the same order they are stored (root -&gt; left subtree -&gt; right subtree);</li>
<li>postfix — elements will be displayed in descending order (left subtree -&gt; right subtree -&gt; root).</li>
</ul>

<p><code node="[object Object]">void bstree_apply_postfix(t_btree *root, void (*applyf) (int));</code></p>
<p><code node="[object Object]">applyf</code> is also a callback function to which the node value must be passed. Such a function could, for example, print values to the screen.</p>
